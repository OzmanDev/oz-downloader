# Glossary

- **Saved song count**: how many songs Spotify has on a playlist that is saved in this app. Shown under the playlist in Saved here. It is not the number of audio files in the download folder.
- **Waiting**: a progress row that has not been downloaded, skipped, or failed.
- **In progress**: a progress row that is downloading now.
- **Skipped**: a progress row for a song that was not downloaded because the audio is already saved, it is a duplicate, the user cancelled it, or a filter matched it.
- **Failed**: a progress row for a song that was not saved. It is not Waiting, In progress, Skipped, or Downloaded. It does not finish the playlist.
- **Downloaded**: a progress row for a song that was saved in this run.
- **Already here**: the audio file is already in the download folder.
- **Downloaded previously**: the song is in the download archive.
- **Already downloaded**: the song was saved earlier in this same run.
- **Unavailable**: Spotify says the song cannot be played.
- **Local file**: the song exists only as a file on the Spotify account, with no stream.
- **No audio stream**: Spotify did not send the audio.
- **Filtered**: the song matched a skip filter.
